¿Necesito asesoría?

Reto rápido: una función que diga si un triángulo es equilátero, isósceles o escaleno.

def tipo_triangulo(a, b, c):
    if a == b and b == c:
        return "equilátero"
    elif a == b or b == c or a == c:
        return "isósceles"
    else:
        return "escaleno"

def main():
    a = int(input("Lado 1: "))
    b = int(input("Lado 2: "))
    c = int(input("Lado 3: "))
    tipo = tipo_triangulo(a, b, c)
    print("Es un triángulo", tipo)

main()

Si no sabrías cómo hacer esto, o al leerlo sentiste que estaba escrito en élfico 🧝, sí necesitas asesoría.
